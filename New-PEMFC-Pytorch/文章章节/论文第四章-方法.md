# 4. 方法

## 4.1 问题形式化

给定时刻$t$的PEMFC传感器读数向量$\mathbf{x}_t \in \mathbb{R}^{24}$，目标是预测该时刻的电堆总电压$\hat{y}_t$。在L=1监督学习框架下,模型输入为单一时间步的特征向量（含多步滞后增强中的lag标记列），输出为对应时刻的电压预测值：

$$\hat{y}_t = f(\mathbf{x}_{t-\tau}, \tau), \quad \tau \in \{1, 2, 4\}$$

其中$\tau$为滞后步长，$\mathbf{x}_{t-\tau}$为$\tau$小时前的传感器数据（特征维度25 = 24传感器 + 1 lag标记）。预测值与真实值$y_t$之间的均方误差(MSE)作为优化目标：

$$\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$$

## 4.2 TFT模型架构

本文采用时序融合Transformer（Temporal Fusion Transformer, TFT）作为基础架构。TFT由Lim等人于2021年提出，最初用于多步时序预测任务，在零售、电力负荷等领域<AI>表现出良好的</AI>可解释性和鲁棒性。本文将其适配至PEMFC退化预测的单时间步回归场景。

图3展示了完整的TFT架构。

**[此处插入图3: TFT模型架构图 (fig3_tft_architecture.png)]**数据流经过四个核心组件：Variable Selection（变量选择）、LSTM编码器（时序编码）、GRN门控残差网络（自适应滤波）和MultiheadAttention（多头自注意力）。每个组件在PEMFC退化预测中承担不同的功能角色。

### 4.2.1 Variable Selection（变量选择）

PEMFC电堆包含24个传感器，其中单电池电压(U1-U5)和总电压(Utot)是退化监测的核心指标，而温度、压力、流量等辅助传感器对预测的贡献可能因工况而异。TFT通过可学习的变量选择权重，自动为每个传感器分配差异化的重要性：

$$\mathbf{w} = \sigma(\boldsymbol{\alpha} + \boldsymbol{\beta})$$
$$\tilde{\mathbf{x}}_t = \mathbf{x}_t \odot \mathbf{w} + \boldsymbol{\epsilon}$$

其中$\boldsymbol{\alpha} \in \mathbb{R}^{25}$为可学习权重，$\boldsymbol{\beta} \in \mathbb{R}^{25}$为可学习偏置，$\sigma(\cdot)$为sigmoid函数，$\odot$表示逐元素乘法。$\boldsymbol{\epsilon} \sim \mathcal{N}(0, 0.01^2)$为训练时注入的高斯噪声（1%标准差），作为正则化手段防止模型对特定传感器的过度依赖。

训练完成后，权重向量$\mathbf{w}$直接反映了各传感器对预测的重要性——权重接近1的特征被模型视为核心信息源，接近0的特征被自主抑制。这为模型提供了静态可解释性：无需额外的特征选择步骤，训练结束即可获得传感器重要性排序。

### 4.2.2 LSTM编码器

加权后的特征向量进入LSTM层进行时序编码。LSTM通过遗忘门、输入门和输出门三个门控机制，在隐状态中累积长期退化信息：

$$\mathbf{f}_t = \sigma(\mathbf{W}_f \tilde{\mathbf{x}}_t + \mathbf{U}_f \mathbf{h}_{t-1} + \mathbf{b}_f)$$
$$\mathbf{i}_t = \sigma(\mathbf{W}_i \tilde{\mathbf{x}}_t + \mathbf{U}_i \mathbf{h}_{t-1} + \mathbf{b}_i)$$
$$\mathbf{o}_t = \sigma(\mathbf{W}_o \tilde{\mathbf{x}}_t + \mathbf{U}_o \mathbf{h}_{t-1} + \mathbf{b}_o)$$
$$\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tanh(\mathbf{W}_c \tilde{\mathbf{x}}_t + \mathbf{U}_c \mathbf{h}_{t-1} + \mathbf{b}_c)$$
$$\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t)$$

虽然输入时间步L=1，LSTM无法在时间维度上展开，但其门控机制仍具有两个关键作用：(1)在batch维度上，由于训练时shuffle=False，batch内样本按时序排列，LSTM的隐状态$\mathbf{h}_t$在batch方向上传递退化的历史信息；(2)LSTM的遗忘门和输入门在隐空间维度上对特征进行选择性记忆，为后续GRN的滤波提供了结构化的特征表示。

LSTM隐藏层大小设置为<mark>96</mark>，层数为1层。采用PyTorch默认的tanh激活函数，dropout在单层情况下不启用。

### 4.2.3 GRN门控残差网络

GRN（Gated Residual Network）是TFT中连接LSTM和Attention的关键中间层。它通过门控机制对LSTM的隐状态输出进行自适应滤波，抑制与预测无关的隐状态维度：

$$\mathbf{a} = \mathbf{W}_p \mathbf{h}_t$$
$$\mathbf{z} = \text{ELU}(\mathbf{W}_1 \mathbf{h}_t)$$
$$\mathbf{g} = \sigma(\mathbf{W}_g \mathbf{z})$$
$$\text{GRN}(\mathbf{h}_t) = \text{LayerNorm}(\mathbf{a} + \text{Dropout}(\mathbf{g} \odot \mathbf{W}_2 \mathbf{z}))$$

其中$\mathbf{W}_p$为残差投影矩阵（当输入输出维度相同时退化为恒等映射），$\mathbf{W}_1, \mathbf{W}_2, \mathbf{W}_g$为可学习权重，$\mathbf{g} \in (0,1)$为门控向量。门控机制赋予GRN选择性传递信息的能力：当门控值接近1时，对应的隐状态维度完整通过；接近0时，该维度被近乎完全抑制。

在PEMFC退化预测中，GRN的作用<AI>很关键</AI>。LSTM隐状态可能编码了多种信息——真实的退化趋势、温度波动引起的可逆电压变化、传感器噪声等。GRN的门控机制自主识别并放大退化相关的隐状态维度，同时压制噪声和波动维度的信息传递。这一设计直接贡献于TFT的训练稳定性——<mark>在FC1上，TFT的Min R²（0.79）远高于纯LSTM（-2.21）；在FC2上，TFT的Min R²（0.89）同样显著优于LSTM（0.83）——</mark>GRN是方差缩减的关键因素（见第5章消融分析）。

GRN的内部隐藏维度设置为128（dim_feedforward参数），dropout率为<mark>0.10</mark>。

### 4.2.4 MultiheadAttention（多头自注意力）

经过GRN滤波后的特征进入多头自注意力层。自注意力机制在特征维度上捕获跨传感器的交互模式：

$$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$$
$$\text{MultiHead}(\mathbf{h}) = \text{Concat}(\text{head}_1, \ldots, \text{head}_H)\mathbf{W}_O$$
$$\text{head}_i = \text{Attention}(\mathbf{h}\mathbf{W}_Q^i, \mathbf{h}\mathbf{W}_K^i, \mathbf{h}\mathbf{W}_V^i)$$

采用4个注意力头（nhead=4），每个头的维度$d_k = d_{model}/nhead = <mark>24</mark>$（hidden_size=<mark>96</mark>）。自注意力后接残差连接和LayerNorm：

$$\mathbf{h}' = \text{LayerNorm}(\mathbf{h} + \text{MultiHead}(\mathbf{h}))$$

在L=1条件下，自注意力在特征维度而非时间维度上操作——它捕获的是"U1和U2是否同步下降""TinH2升高是否伴随Utot降低"等跨传感器的退化模式。这种"单时间步的全局特征交互"是对LSTM时序编码的补充：LSTM提供了逐传感器的时间演化信息，Attention在此基础上建模传感器之间的退化一致性。

### 4.2.5 输出层

经过以上四个组件处理后，取注意力输出层的最后时间步（L=1下即为唯一时间步），通过全连接层输出最终预测值：

$$\hat{y}_t = \mathbf{W}_{fc} \mathbf{h}'_{[1,-1,:]} + b_{fc}$$

## 4.3 训练策略

### 4.3.1 优化器与学习率调度

本文采用<mark>Adam</mark>优化器，参数设置为：学习率<mark>$3\times10^{-4}$</mark>，权重衰减<mark>$1\times10^{-5}$</mark>，$\beta_1=0.9, \beta_2=0.999$。<mark>配合ReduceLROnPlateau学习率调度（patience=20, factor=0.5）。</mark>

学习率调度采用ReduceLROnPlateau策略：当验证损失在连续<mark>20</mark>个epoch内未创新低时，学习率减半。初始学习率<mark>$3\times10^{-4}$</mark>对应最多4次减半（降至约$1.9\times10^{-5}$）。

同时启用梯度裁剪（max_norm=0.5），防止LSTM在长序列上的梯度爆炸。

### 4.3.2 随机权重平均（SWA）

本文采用随机权重平均（Stochastic Weight Averaging）以提升模型的泛化性能。SWA在训练后期（epoch 40起）收集模型参数的指数移动平均，训练结束后以平均权重替代最终权重进行评估。SWA的核心优势在于将优化路径上多个局部最优解进行平均，得到的解通常具有更宽的损失盆地（wider minima）和更低的泛化误差。

$$ \boldsymbol{\theta}_{\text{SWA}} = \frac{n_{\text{SWA}} \cdot \boldsymbol{\theta}_{\text{SWA}} + \boldsymbol{\theta}_{\text{current}}}{n_{\text{SWA}} + 1} $$

### 4.3.3 早停与最大训练轮数

最大训练轮数设为<mark>500</mark>。早停机制监控验证损失，patience设为<mark>100</mark>个epoch。在FC1和FC2上，训练通常在100-270个epoch内触发早停。

## 4.4 评估协议

### 4.4.1 Loop 50重复实验

由于深度学习模型对初始权重敏感，单次训练的结果具有随机性。本文采用"Loop 50"评估协议：使用50个不同的随机种子独立训练同一模型架构，报告R²的最小值(Min)、均值(Mean)和最大值(Max)。这一协议不仅展示了模型的最佳表现（Max R²），还通过Min R²评估了训练的稳定性和可复现性——这在工程实践中尤为重要。

### 4.4.2 Top-5集成

取50次训练中验证集R²最高的5个模型，对其在测试集上的预测结果取算数平均：

$$\hat{y}_{\text{ensemble}} = \frac{1}{5} \sum_{i=1}^{5} \hat{y}_{(i)}$$

其中$\hat{y}_{(i)}$为验证集R²排名第$i$的模型的预测值。集成学习被广泛证明可以降低预测方差、提升鲁棒性，且不改变模型架构或训练流程。

### 4.4.3 评价指标

本文采用四个指标评价预测性能：

**决定系数(R²)**：
$$R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}$$

**均方根误差(RMSE, V)**：
$$\text{RMSE} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2}$$

**平均绝对误差(MAE, V)**：
$$\text{MAE} = \frac{1}{N}\sum_{i=1}^{N}|y_i - \hat{y}_i|$$

**平均绝对百分比误差(MAPE, %)**：
$$\text{MAPE} = \frac{1}{N}\sum_{i=1}^{N}\left|\frac{y_i - \hat{y}_i}{y_i}\right| \times 100\%$$

此外，对于RUL预测任务，报告RUL预测的绝对误差和相对误差。

## 4.5 对照模型

为验证TFT各组件的贡献，本文设置了以下对照模型进行消融实验（均采用与TFT相同的训练超参数和Loop 50评估协议）：

**DLinear** (AAAI 2023): 时序分解+线性映射。通过移动平均将输入序列分解为趋势和残差，分别用线性层预测后求和。在L=1条件下退化平均退化为恒等映射，本质为纯线性回归。代表"无时序、无非线性"的下界。

**ResMLP**: 残差MLP回归模型。由两层全连接网络+残差连接+LayerNorm组成，代表"非线性但无时序记忆"的基准。

**LSTMBaseline**: 标准单层LSTM+全连接输出，无Variable Selection、无GRN、无Attention。代表经典时序模型的基准。

**TSMixer** (KDD 2023): 全MLP时序预测模型。通过堆叠的特征混合MLP块+残差连接进行预测，不使用LSTM和Attention。代表2023年最新的"无循环"时序预测方法。

**TFT（本文）**: 完整四个组件：VS + LSTM + GRN + MultiheadAttention。

<mark>在RTX 3070 Laptop GPU（8GB显存）、batch size=64配置下，TFT单次训练（500 epochs上限，通常在100-270 epoch触发早停）耗时约3-5分钟。50次独立训练（Loop 50）的总耗时约2.5-4小时。单次推理（前向传播）延迟约0.3ms——在1Hz传感器采集频率下，推理开销可忽略不计。</mark>

对照模型的选择逻辑是递进的：DLinear验证"是否需要非线性"→ResMLP验证"是否需要时序记忆"→LSTM验证"是否需要门控和注意力"→TSMixer验证"是否需要循环网络"→TFT验证"四个组件同时工作的综合效果"。
