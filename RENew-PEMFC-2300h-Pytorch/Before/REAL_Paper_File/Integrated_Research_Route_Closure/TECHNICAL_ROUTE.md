## 3. 物理约束不能接入的四类原因

|问题层|当前障碍|补一张曲线或一个超参数是否能解决|
|---|---|---|
|数学结构|H1/H2/H3输出是固定j≈0.78923下的单个R；跨电流∂V/∂j没有被模型定义。对时间求导或对Ridge系数求导都不能冒充它|不能。需要有真实观测支持的跨电流观测算子/输出坐标；不是把现有导数设为0|
|测量与参数|Rdiff是综合斜率，含多种损失与状态；C仅1/5拟合支路通过局部数值筛查；EIS的R0非认证HFR，串号/接线映射及ASR身份不全|不能。需要参数身份、可辨识性、条件域和不确定性，不可把缺失损失项置零|
|时间可用性|极化/EIS缺准确耐久时钟和结果发布时刻；部分来源比预测起点晚；TFT模型选择也有截止时刻|不能。结束时间下界不能替代认证发布时间；未来参数不准作为教师或输入|
|样本与辨识|仅7个极化事件、3个合法SOH回放，同一轨迹；固定j下Eeff−Reff*j设计秩1而参数2|不能。更多重叠窗口/电流行不增加独立寿命，也不能识别两个混叠参数|

因此A/B/C保持`PHYSICS_DESCRIPTIVE_ONLY`，P-A/P-B保持`PHYSICS_INTERFACE_NOT_QUALIFIED`。没有`PHYSICS_LOSS_TRAINING_QUALIFIED`。真实健康训练的物理损失、有效梯度和公平消融成绩均为NA。本轮不存在“尚未达到0改善”的物理训练，而是尚未取得可计算的合法训练对象。

普通时间平滑与跨电流物理关系不同，不能换名。实测保持率存在上升，不能强制单调老化。极化参数变化也不能直接归因于不可逆损伤。

## 4. 坚持单RealHyFC，实际训练贡献最少缺什么

这里区分“可在同一数据集中补查的资料”和“补查后也可能不存在的证据”；不能承诺靠继续训练就一定齐全。

1. **观测坐标与对象身份：**同一堆/单体映射、面积归一化、真实跨电流V-j点、扫描方向、稳定停留时间以及同步T/RH/压力/供气条件。若希望约束健康输出，先定义这些点怎样构成同一健康状态的可观测读出；不得想象模型有未观测的输出。
2. **独立物理参数：**若选电阻类约束，须有可信HFR/ASR测量定义、接线去嵌与辨识支持；若选曲线形状，须有可比方向/条件和非零损失的实际训练样本。不是每条路线都必须HFR，但每条都必须有自身可识别的观测依据。
3. **因果时间表：**所有物理测量、处理结果与参数估计的可用时刻、耐久时钟映射、模型选择截止。只可用于之后的起点；未知就标未知，不反向指派到更早样本。
4. **可训练接口：**明确输入/输出、量纲、真实损失、连接到哪个参数的梯度；损失不能与普通统计正则等价。先在真实Train检查非平凡性，再谈GPU。拟合极化曲线的非零梯度不证明H1/H3参数接收到梯度。
5. **同信息同容量对照与验证：**物理组和无物理组得到相同额外信息，容量、训练预算和取样一致；冻结成功/停止条件。需要足够过去事件训练和后续独立目标评价；三事件不能支持大量校准自由参数或泛化宣称。

这些条件缺一，就不能把“软物理约束提升H1/H3或SOH”列为已实现贡献。即使它们日后齐全，也仍不补齐真实EOL。

## 6. 无真实EOL时RUL可以研究什么

允许：解释EOL资格、终止机制与潜在删失条件；在明确阈值、运行情景、时间单位和趋势假设下展示条件剩余时间及假设敏感性；讨论为什么短期误差不足以验证长期交点。历史calendar情景保留，不作为新结果重复计算。

条件交点可写为`Lθ(t | scenario)=inf{u>0: SOH_scenario(t+u)≤θ}`，但它不是已观测真实RUL。无交点应报告未达到/不可识别，不能替换成很大的确定寿命。

不允许：设置90%或95%就称官方失效；用记录末端−t造标签；报告真实RUL RMSE/提前预警可靠性；将物理诊断、短期代理区间或交点敏感性带当失效时间置信区间。右删失也需要先定义failure、证明截止时未failure、明确停止原因；目前不能自动视为已经认证的删失生存数据。单条轨迹不能识别可靠寿命分布。

统一方法按同一套数据与时钟合同组织，而非宣称全部模块已端到端耦合：

2. M1：冻结TFT动态预测，报告三seed与尾部限制。
3. M2：真实P1S观测算子与96h H1主任务、H3辅助、H2探索性逐周期接口。

## 8. 下一项只建议一个实验：1500h恢复干预前后配对诊断

**要解决的具体缺口：**当前P1S/极化变化中有多少与可恢复运行状态相符，是否应把性能变化直接当作不可逆退化？这是健康解释和物理约束适用性的前置问题。它不重复H1/H2/H3，不围绕三个SOH事件继续优化，也不再盲拟合另一个PINN公式。

**现有数据：**`Polcurve_Nominal_RHFC_1500h.csv`与`Polcurve_Nominal_RHFC_1500h_afterAirAirStart.csv`，原论文第4页干预方法，既有稳定平台提取规则及测量时钟资格。现阶段只有文件存在/大小证据，不能提前写已经观察到恢复改善。

**最小规模：**2个Development文件、1次配对干预；复用固定平台与四窗口分析，无新模型、无超参数搜索、无GPU、无新SOH校准。输出一个按同电流、同方向匹配的前后电压差CSV与一张配对图，附条件差异和时间身份表即可。

**运行前冻结的门槛和方法：**

1. 先只检查文件身份与测量日历，确认同一对象、真实先后顺序、干预语境及Development资格；不凭1500文件名给出准确耐久小时或当时发布时刻。若身份/Development界限不确定，停止数值分析。
2. 沿用上一阶段设定电流0.36–1.80A/cm²、平台≥299s、j标准差≤0.005A/cm²、|V漂移|≤2mV/min、T和露点跨度≤2°C、middle50主窗口与其他三窗口敏感性。不得见结果后放宽。
3. 只配对相同设定电流和扫描方向；另外要求前后平台平均入口T与露点差各≤0.5°C、出口压力差≤2kPa、化学计量比差≤0.1，实际通道缺失则该配对不合格。每个方向至少3个合法电流点，且j*=1须被真实合格点包围；否则相应结论不可评价。
4. 计算`ΔV(j)=V_after(j)−V_before(j)`及综合斜率变化，保留全部未匹配和被剔除记录；不把差商称膜阻。若计算j*=1差，仅作诊断读出，不替换冻结SOH标签。
5. 以四窗口差值范围及实际时间波动报告敏感性，不作把每行当独立样本的显著性检验。若方向/窗口不一致、环境不匹配或差值与波动不可区分，结论为不可解释/不确定，不标记0恢复。

**科学成功标准：**获得满足上述门槛的真实配对，说明变化是否与可恢复状态解释相符，并量化其方向/窗口依赖；即使明显回升，也只是一例干预相关变化，不能排除顺序、时间与其他状态混杂，更不识别全部不可逆损伤。

**停止条件：**数据资格或配对不足即停；完成这一组固定诊断后即停，不换窗口/阈值/拟合公式救结果。无论结果正负，不自动启动物理训练、修改H1/H2/H3或M2_NC，也不训练RUL。只有新的观测算子、参数、时间与对照资格逐项成立，才另行申请最小训练对照。

这项实验有明确新增的真实干预依据，能推动论文中的健康意义与物理适用域解释；它不会自动补齐数学接口、发布时刻或真实EOL。若负责人坚持本论文必须含已验证物理增强训练和真实RUL，需先取得第4/6节列出的原始资料与验证条件，不能继续以模型搜索替代。
