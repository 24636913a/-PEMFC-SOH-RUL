# 健康特征提取使用说明

本阶段结论：BLOCKED（跨两堆统一二维表示未取得资格）。FC1有条件的离线描述性结果保留；RealHyFC冻结稳态规则下不足以拟合。没有训练或预测。

请先读健康特征验证报告.md、特征提取方法说明.md。最终有效数据和图片：

`输出结果/历史核验/20261025T153526_430847`

根输出目录保留首次数值计算，后续历史核验目录是同一真实CSV的显示/资格判定修正，不是重新调参数；最终交付索引.json唯一指定本次正式展示版本。原数值全部保留，初次判定及显示问题见首轮显示与判定记录，故障记录也保留。

配置在任何特征拟合前冻结。0.3–1.0 A/cm²为候选网格，实际只使用合格代表点括定位置，不外推。1°C温度筛选及其他工程阈值是本阶段保守政策，不是经过验证的物理等价标准。

正式完整程序位于同级“完整代码”，包含阶段0与阶段1。开发入口为程序/健康特征主程序.py；复算为程序/独立复算核验.py；平台检查为程序/平台可靠性复核.py。从项目Python 3.11.9执行：

```powershell
python -X utf8 -B 程序/健康特征主程序.py --check-only
python -X utf8 -B 程序/健康特征主程序.py
python -X utf8 -B 程序/独立复算核验.py --output "实际输出目录绝对路径"
python -X utf8 -B 程序/平台可靠性复核.py --output "实际输出目录绝对路径"
```

再次运行会独立保存，不覆盖已完成运行。--redraw-from只从SHA核对的已有真实CSV重绘，不重新拟合特征。正式代码归档同步.py是本次从阶段0_v1到阶段1_v1的一次性发布程序，不可重复调用覆盖新版本。

主要图：FC1相对初始极化电压损失、二维特征随标称老化小时变化、一二维拟合对比；RealHyFC平台覆盖与提取拒绝依据；二维稳定性和负载留组对比。PNG为300dpi，另保存PDF。RealHyFC没有资格的曲线图不生成空图充数。所有CSV保留原始路径、行号、时间资格和启停身份。

只允许解释数学损失分量，不解释为活化/欧姆机理参数，不将同曲线采样点当独立老化样本。未执行Git提交或推送。
