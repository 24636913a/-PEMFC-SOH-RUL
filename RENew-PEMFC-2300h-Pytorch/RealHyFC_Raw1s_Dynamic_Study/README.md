# RealHyFC 原始约1秒动态电压预测

唯一数据源为仓库已有17个 RealHyFC Loadcycle CSV；原始文件是权威数据。历史代码、权重和研究目录只读保留。本研究不涉及IEEE PHM 2014，不构造RUL标签，也不把动态电压预测称作SOH估计。

阶段依赖：P0原始完整性/双时钟审计 → P1既有历史问题解释 → P2仅Train定阈值并冻结协议 → P3 Seed202小规模串行GPU试验 → P4报告与原始图数据。

`cache/` 是可重建的本地内存映射文件，不提交Git。所有派生结果仅写入本目录。模型输入的24维物理/因果派生字段、采样起点和超参数须在首次训练前写入协议；模型评价使用全部未来秒级目标，保留原始目标时间戳。

复现命令将在正式协议中列明。研究由AI辅助编程和核查；数值结论仅来自保存的实际运行产物。

输入窗口说明：本轮300条模型输入中的过去30点电流统计另有29条因果预热，最早原始信息支持约328秒；不是严格只使用最近300秒原始信息的基准。详见03的预热支持说明。

## 查看结果

首先读00–05六份中文报告。`outputs/all_metrics.csv`是全部四分区/三模型/两跨度的全样本及事件/普通分层数值；`runs/`包含真实checkpoint、日志和逐目标预测NPZ；`figures/events/`与`figures/results/`每图有300dpi PNG、PDF及绘图CSV。

## 从新克隆独立复核

先完整获取原17份Git LFS CSV，然后在本目录运行：

```powershell
python -B scripts/audit_raw.py --rebuild-cache
python -B scripts/verify_runs.py --horizon 30
python -B scripts/verify_runs.py --horizon 120
```

重建缓存只接受空/不存在的cache，审计中间结果保存在本研究`work/`，不覆盖原始数据、冻结协议和训练产物。核验器按所有查询重新读取原始CSV、核对原始时间戳/窗口/分区、独立计算指标并核对checkpoint和真实日志。

本轮首次工程开发期间曾有一次F2在优化器0步前的设备兼容失败；修复的是新适配器的Lightning设备属性，记录保留且同初始化恢复。完整可训练模型实例固定为4个；没有以性能为依据额外重训。研究结果不与历史12小时任务直接比较。
