# 真正影响投稿的缺口与最小后续方案

本轮未训练任何模型，以下只是负责人审核用方案，不是自动执行清单。O1已做完的尾部/24步/目标等权不再列缺失；本轮Persistence与Train历史工况分析也已经完成。继续训练更多优秀F2种子不能填补独立性和结构归因缺口。

如果只能补2～3项，按以下顺序考虑：

1. **同协议简单强基线。** 最小可选为LSTM和TCN各3个预先固定、未经筛选的Seed，共6次训练；严格复用同1380/205窗口、同14槽/Top10/EWMA、Train-only scaler、同目标与评价规则，先冻结容量/训练预算/成功和停止条件。它解决模型池狭窄，而不是寻找新的backbone。旧N2三fold、233/245/466验证窗口及batch64/max300/pat30、per-horizon目标scaler不能直接复用。停止于固定预算，不因F2未胜出再调基线或换Seed。

2. **真正合格的时间外评价。** 先核验访问历史、独立性、变量和采样兼容性，再冻结完整模型集合统一评价。当前仓库的既有暴露区域不能重新命名为未见Test；若没有新的未暴露、合法RealHyFC记录，这一项只能明确缺失，不能通过随意重切分或读取现有Test来补。是否取得新的合法记录由负责人决定，本轮没有获取数值或访问Test。它解决推广范围，而不是再改善已经反复使用的Validation。

3. **部署型困难转换验证（有合格记录时）。** 在第2项成立后，按起点已知历史工况或预先给定负载计划冻结switch/恢复等评价规则，统一报告24步和终点/尾部。最小是复用全部既有冻结模型前向，无新主干。未来实测工况只能事后审计，不能作为未知未来预测输入；若没有起点已知计划及足够合法样本，则停止并不报在线泛化成绩。

不把再次独立训练门控消融列优先项：P2已做9次、得到不一致/负面结果，应如实进入论文。若仍坚持独立门控增益主张，需要另行预注册且未经选择的对照预算，但当前更节省研究资源的选择是弱化该项主张。也不为借鉴参考论文而补SOH、RUL、PINN或物理损失。
