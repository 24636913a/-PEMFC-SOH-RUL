# Identifiability assessment

**Q_ERROR_SUPPORTED, with limits.** Strict causal training OOF contains sufficient, temporally distributed E1/E2 state-error events; Validation E1 has similar zero-q false-positive characteristics. Frozen physical counterfactuals show that q correction is the only robustly dominant intervention in both required diagnostic scopes.

This does **not** prove that future q is deterministically identifiable from history, nor does it authorize use of real future conditions. Conditional-statistics-only effects are weak/inconsistent, and un-intervened peak-to-peak and transition features retain forecast error. The only next candidate is a preregistered probabilistic physics-consistent future-condition model; no model experiment is authorized in R0.

Evidence: the event, calibration, counterfactual, and remaining-condition files named in this directory.
