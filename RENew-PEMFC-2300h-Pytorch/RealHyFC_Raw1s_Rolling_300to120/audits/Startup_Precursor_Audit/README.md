## 实际会做什么

1. 从17份原始Loadcycle CSV重新分块读取，核验历史清单的大小、SHA256、行数；不读取当前F2运行目录和缓存。原始DateTime不舍入，保留原始文件ID和行号，按真实时间断点/文件边界断段，不插值、不按电压大小删数据。
2. 用U1–U5及U7–U11十通道均值检出相邻记录的正/负跃迁；U6独立保留。新7:1:2 Train中|一步ΔV|的99.5%分位数为主阈值，历史0.038477648942V仅作可比性参考。保留全部逐秒触发，按同段同分区触发间隔≤120秒合并，不能把触发秒数当独立启动次数。
3. 对全部事件保存前后180秒的十单体、实际/设定/内部设定电流、电流密度、状态码、温度、压力和可用气流等真实上下文；缺失仪器不删除电压事件。A–F为非互斥观测标签，不是故障诊断。相邻值变化、事件时刻值、过去前兆分别保存。
4. 在事件前120/60/30/10/5/1秒及事件时刻按DateTime向后匹配（最多0.1秒误差，不取请求时间之后的记录）；计算值、过去30/120秒增量、实际时间OLS斜率和范围。断点或缺测记NA。
5. 温度/压力六个固定因果信号及两种组合只用起点及以前数据，阈值仅Train拟合。每一个合法逐秒起点检查未来30/60/120秒内事件，输出Precision、查询Recall、误报率、基础发生率、独立事件ID层面的覆盖/Recall、报警段数和真实有效暴露小时。**另算约提前整H秒的事件检测率**，不能把发生前1秒的信号宣传为提前120秒预警。
6. 普通对照包含所有正负事件段前后120秒以外的真实时刻，使用相同特征与Train阈值，报告普通温压变化是否也经常触发报警。Train、Validation、已暴露Holdout分别报告；Holdout只做冻结规则的探索性描述，不能选参。
7. 65秒检验独立按零设定停留段统计：回顾性选择段内最大正向电压跃迁，与首次正电流指令、首次非零实际电流及至少5A持续5秒的带载代理比较；仅有明确起止、同连续段且跃迁时实流接近零的段进入可比统计，长/短停留分开，删失和反例保留。这个回顾性锚点**不是预警标签**，更不会写入F2规则。
8. 只读已有RCR周期表/模板，在原覆盖范围对齐。计划30/15/30/93分钟、最早RCR周期的实测零命令相位、实际命令、实际电流、电压恢复分开处理；不在后段强行外推146个旧周期，不宣称未来计划已在起点发布。

详细定义、所有截止值、缺测/边界和解释限制见 `docs/PROTOCOL_AND_LIMITS.md`。

## 科学限制

零电流不是完全关机真值，operation_point不是硬件开关位，记录1Hz不是全部仪器独立1Hz刷新。气流/温压的时间关系是观测旁证；缺少独立控制器、阀门、测量链路等证据时不能证明物理因果。前兆对比不做把重叠秒数当独立事件的统计显著性检验，也不保证温度或压力一定有效。

**尚不能证明任意起点已知未来120秒的准确控制计划。**

本次仅提交新增代码、配置和说明。原F2主程序、原始数据、已有缓存、权重、预测和用户正在生成的训练结果均不属于本次提交范围。数据读取、事件清单、误报/召回、65秒比例、RCR匹配、绘图和自动报告目前全部**待用户运行**。
