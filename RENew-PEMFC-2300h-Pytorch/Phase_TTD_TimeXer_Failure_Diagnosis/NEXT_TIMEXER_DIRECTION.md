# Next TimeXer direction

NO_MODEL_EXPERIMENT_AUTHORIZED.

The only defensible next step is a separately preregistered state-transition robustness study, scoped to validation folds and using the frozen task/splits. It must test whether predictions can be made robust to rare false mixed-state events without using future actual current, leakage, threshold search on Test, or post-hoc removal of harmful segments. It should predefine event support, success metrics, seed policy, and an intervention radius before any training begins.

This is a planning direction, not authorization to train, modify TimeXer, or enter a new phase.
