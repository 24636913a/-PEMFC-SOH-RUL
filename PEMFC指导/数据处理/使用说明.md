# 阶段0原始数据核验

入口：`程序/数据核验主程序.py`，配置：`配置/数据核验配置.yaml`。使用项目实际Python 3.11环境。需要NumPy、pandas、matplotlib、openpyxl、PyYAML；不需要torch或GPU，不自动安装软件。

```powershell
python -X utf8 -B 程序/数据核验主程序.py --check-only
python -X utf8 -B 程序/数据核验主程序.py
```

从本目录执行上述命令；其他工作目录可使用入口的完整路径。`-X utf8`避免Windows控制台对原始异常Unicode表头的编码错误；`-B`避免写入pycache。

程序从原始文件实际读取，不用模型缓存或预测标签代替。RealHyFC由已有17文件清单定位，重新SHA核验后逐块读取；极化曲线包含用户本阶段授权的全部名义检查点及两次afterAirAirStart。FC1读取当前实际存在的Ageing及Pola表。

输出：`输出结果/图片`、`输出结果/表格`，以及本目录两份中文报告。重复运行不覆盖原输出，自动在`输出结果/历史核验/<时间>`生成新现场及报告。错误保留`失败记录.txt`和部分源登记，不自动改变规则或修复原始数据。

统计保留所有原记录；RealHyFC绘图固定60行抽样，并保留块端点与断点两侧，全部抽样原点、源行号及连续段ID单独保存。没有滤波、平滑、插值、归一化、预测误差或健康特征拟合。

扫描方向以实测j累计0.05 A/cm²幅度的滞回确认描述，未定阶段保留0；它是绘图方向诊断，不是仪器精度或已认证的扫描转折时刻。参考0.9 A/cm²只检查测量邻域和分段括定支持，不在本阶段插值。

FC1极化表若没有真实时钟，保持NOMINAL_ONLY。RealHyFC缺OpHrs2时以实际日历时间找前/后运行观测，仅给累计小时边界，禁止用文件标称小时或固定计时器偏移冒充精确对齐。测量结束与结果发布时间分别记录。

完成真实核验后才同步整套程序、配置和依赖记录至`../完整代码`。旧正式版本存在时先完整备份及SHA校验；首次只有空历史目录，不制造历史副本。同步检查失败保留失败代码现场并恢复已备份旧文件。

最终数据状态仅允许PASS、CONDITIONAL_PASS或BLOCKED；状态从真实结果生成。数据可读不能单独证明物理条件可比或因果标签可用。
