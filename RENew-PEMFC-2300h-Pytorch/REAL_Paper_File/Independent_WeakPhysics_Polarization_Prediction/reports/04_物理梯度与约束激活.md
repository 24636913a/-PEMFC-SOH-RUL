# 真实作用与不增益
12个物理组、共30000步，70步（0.233333%）同时有Lphys>1e−16与梯度L2>1e−12。各Run仅前4–8步激活，此后真实物理损失为0，不是NA。A任务物理组共16步，B任务共54步；最晚为epoch8。

真实最大物理参数梯度L2=0.0194022342，加权物理/数据梯度最大比=0.023660984。初始化真实Train、训练过程逐epoch、最终评价导数均保存。普通模型也只需早期数步就达到网格单调。

独立NumPy解析SiLU前向及导数复现全部权重预测，最大V差1.11e-16，斜率最大差8.33e-17Ω·cm²；真实Train参数方向有限差分最大差2.33e-12。

最终A/B模型在每个评价网格的违例率、正斜率RMS均为真实0。这既不证明连续域全局单调，也不提供物理组额外优势。MAE变化约0.007%/0.012%，只有微伏以下量级，不构成清楚可重复的物理增益。

因此`PHYSICS_ACTIVATED_DURING_TRAINING`与`PHYSICS_DESCRIPTIVE_ONLY_NO_INCREMENT`同时成立；**不能错误标成整轮PHYSICS_CONSTRAINT_INACTIVE**。本轮失败不是导数或训练不可计算，不是隐藏无数据问题，而是已学会形状的普通模型使该弱约束几乎冗余。不会增大λ、改损失或改采样域救结果。
