## 1. 已证实的新增依据

FC1原作者Pahon等的数据论文，DOI：[10.1016/j.dib.2022.108601](https://pmc.ncbi.nlm.nih.gov/articles/PMC9679439/)，已取得完整XML。以章节和表号定位，不编造未取得PDF的页码。S01 Data Description (1)(c)与Table 3支持Txxx为老化时刻、8个测试标签；Excel发布形式在原文有说明。本地42文件与目录数量相符，仍缺官方归档逐字节核对。参见F01/F07。

S01 Experimental Design (2)(b)与Table 3明确：极化是1至0 A/cm²约1000秒连续降载；极化后EIS的15分钟稳定期不是极化各点停留协议。S01 Data Description (1)(a)给出氢气/空气入口28/42°C、冷却液出口55°C、气体入口1300 mbar绝压等名义条件。这些是协议依据，不是每次曲线的同步实测温压（F03–F06）。

因此，FC1标称测试时点比“只有文件名猜测”有更强的原作者依据，但原NOMINAL_ONLY记录保持不变；没有获得其精确测量起止日历时间或结果发布时间。

RealHyFC耐久数据官方登记为[Zenodo 20715542](https://zenodo.org/records/20715542)，对应原论文10.1016/j.ijhydene.2026.156060。11份本地极化文件MD5全部与官方逐字节匹配；SHA也与阶段1.2一致，见原始文件来源身份复核.csv。确认的是来源身份，不是测量误差已消失。

直接引用的方法论文10.1002/fuce.70057已从[官方方法数据登记](https://zenodo.org/records/19068126)取得原PDF。PDF3页2.2.1说明先降后升、16负载点、5分钟/低负载2分钟平台、每条曲线前30分钟预调理。PDF3页2.2说明表征序列之间至少休息8小时；该语句不能补出耐久试验各文件实际休息时长（R07/R08）。

## 2. 温度和压力到底确认了什么

原耐久论文PDF2–3页及方法论文PDF3–4页支持冷却液入口/出口、气体入口/出口的区别。Real的70°C为冷却液入口名义设定；160/150 kPaG为气体出口压力。方法论文Table 1中的50 kPaG属于冷却液入口，不能错用到阳极/阴极气体入口（R01/R04/R06）。原文页截图已逐项查看，避免表格抽取错列。

仍缺：该试验台冷却液温度传感器型号、校准/准确度、允许温控峰峰摆动、入口压力允许波动和记录同步机制。两篇论文的敏感性档位是人为改变工况的试验范围，不能当作同条件测量允许误差。原1°C/3 kPa筛选结论均不改，不能声称原论文认可取消1°C（R02/R03/R05）。

厂商公开G200通用手册2页有设备控制范围及通用电压监测指标，但不是本数据设备的配置/校准证书，更不是温度准确度。CDDM校准、EIS误差、入口温度数值间隔也不能替代冷却液温度准确度。约4.07秒记录周期沿用历史观察，控制器或仪器原因仍未知（R02/R10）。

## 3. 两个不能忽略的来源差异

第一，FC1原文声明采集1 Hz，而本地三份老化表既有正时间差中位约30.202–30.203秒。前两份各65535行是现有记录事实，但本轮没有证据判定差异来自抽样、导出或其他处理。不能静默恢复采样率、填点，或据此认定数据造假/损坏。该差异与无时钟极化表的采样频率不是同一个问题（F08）。

第二，RealHyFC方法与耐久两个官方数据集的同名BoL极化文件MD5及大小不同。方法论文为10片堆；耐久论文PDF2页明确BoL完整EIS敏感性另用8片新堆。同项目、同名文件及同批次MEA不等于同一试验身份。没有借方法数据的电压或敏感性系数修正现有健康特征（R09）。

## 4. 时钟和结果可用时间

FC1仍只有可信的标称老化标签，缺实际诊断日历时钟。Real有DateTime与运行小时区间；300h曲线区间312.15411–327.81354h，600h曲线区间566.16980–615.66968h。前者不能用于严格300h截止，后者不能默认严格600h可得（T01/T02）。

所有逐次诊断处理、质检与向预测者开放的时刻仍未确认。物理测量结束只是潜在最早下界；若已知使用原始记录，另需确认通道、采集延迟和提取程序当时是否已固定。现在离线能算出D，不说明过去模型当时确实能得到D（T03）。

官方登记的2026-06-29（耐久）和2026-06-03（方法）是数据公开日期，不是2024/2025逐次诊断在线结果可用时刻。目录修改时间、Excel属性、论文接收日期均不能替代。

## 5. 证据强度与未完成事项

已证实：原作者协议、字段身份、Real官方文件MD5和阶段1.2固定特征支持。合理推测：名义条件控制与同方向扫描有助于堆内比较；但无法定量排除温压和恢复影响。仍未知：实际传感器公差、条件独立的真实退化量、同健康状态跨日期重测、逐次信息可用时间、可核验的真实EOL。

未发现资料只表示本轮核阅范围内没有找到，不等于资料永久不存在。FC1官方门户503、网页/PDF访问失败均保留记录；原作者XML已成功取得。没有绕过访问控制或下载重复原始数据大包。
