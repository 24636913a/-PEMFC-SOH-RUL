# 3. 数据与预处理

## 3.1 数据集描述

本文采用IEEE PHM 2014 Data Challenge提供的质子交换膜燃料电池（PEMFC）退化数据集。该数据集记录了1kW级PEMFC电堆在两种不同运行条件下的长期耐久性测试过程，包含FC1（准静态工况）和FC2（电流纹波工况）两个子数据集。表2总结了数据集的主要特征。

每个采样时刻记录了24个传感器读数，可归纳为四类：(1)电压类——5片单体电压(U1-U5)和电堆总电压(Utot)，是退化状态的核心表征；(2)电流类——电流密度(J)和电流(I)，反映负载水平；(3)温度类——氢气、空气、冷却水的进出口温度(共8个)；(4)流量/压力类——氢气、空气、冷却水的进出口压力(共6个)和流量(共5个)。传感器全称为：

<mark>本文以FC2（电流纹波工况）为主实验数据集，FC1（准静态工况）为交叉验证数据集。</mark>两种工况具有不同的退化特征。<mark>FC2为电流纹波条件——负载的周期性波动导致电压和各传感器读数出现动态变化，其传感器动态丰富度在可用数据集中最高，模拟了车用燃料电池负载动态变化的一个维度（电流纹波），因此被选为主要研究对象。需要注意的是，实际车用场景还包含频繁启停、热瞬态、怠速等FC2未覆盖的因素。</mark>FC1为恒定电流负载下的准静态退化，电压随时间平滑下降，传感器读数变化<AI>非常</AI>平缓——在约1000小时测试中，Utot下降幅度仅为约5.6%（从3.364V降至3.186V）。

<AI>需要说明的是</AI>，FC2原始数据中Utot范围异常(2.865-4.986V)，最小值低于电堆正常工作区——这是纹波负载下瞬时采集的奇异值，需通过滤波处理。

## 3.2 预处理流程

本文设计了统一的五步预处理管线，如图2所示。

**[此处插入图2: 数据预处理流程图 (fig1_preprocessing_pipeline.png)]**预处理目标是从高频原始数据中提取适合监督学习的结构化样本，同时保留退化过程中的时序信息。

### 3.2.1 降采样

原始数据采样间隔约30秒（~0.0083小时），在1000小时尺度上累计约12万-14万个时间点。然而，燃料电池的老化是缓慢过程——在数十分钟甚至数小时尺度上，退化量远低于传感器的测量噪声水平（±0.005V量级）。过密采样不仅增加计算负担，更导致相邻样本高度重复，模型难以学习到有效的退化梯度。

本文采用1小时（整数小时）均匀降采样。具体操作为：将Time(h)取整后去重，保留每个整数小时的第一个采样点。降采样后FC1为1155个时间点，FC2为1021个时间点。

### 3.2.2 Savitzky-Golay滤波

PEMFC测试过程中存在传感器噪声、电磁干扰和瞬时工况波动。为保留退化趋势同时抑制高频噪声，本文采用Savitzky-Golay（SG）滤波。SG滤波通过在滑动窗口内拟合低阶多项式来平滑数据，相较于移动平均法，SG滤波在抑制噪声的同时更好地保留了退化曲线的斜率变化——这对捕获退化速率的阶段性转折至关重要。

滤波参数设置为窗口长度21（约21小时）、多项式阶数2。对24个传感器分别进行滤波处理。经SG滤波后，FC2原始数据中的异常值得到有效抑制。

### 3.2.3 特征选择

本文使用全部24个传感器作为输入特征，不做人工筛选。这是基于以下考量：首先，TFT架构内置的Variable Selection机制可以自动学习各特征的差异化权重，人工预筛选反而可能遗漏关键信息。其次，PEMFC是一个强耦合的多物理场系统，温度、压力、流量等"辅助"传感器可能含有对预测有价值的信息——例如冷却水温度的变化可能预示电堆内阻的缓慢上升。因此，本文选择了"全特征输入+模型自适应加权"的策略，将特征选择权交给模型。

### 3.2.4 L=1监督学习 + 多步滞后增强

这是本文最关键的预处理设计。传统时序预测多采用滑动窗口方法——将连续L个时间点的数据作为输入序列，预测下一时刻的目标值。然而在PEMFC退化场景中，滑动窗口面临根本性困难：在1000小时的退化过程中，Utot的下降幅度仅约5.6%，平均每小时下降约0.00018V——远小于传感器的测量噪声(~±0.005V)。以常见的L=10窗口为例，10小时内电压变化约0.0018V，LSTM需要在噪声中学习到这个幅度——这在数学上等价于从信噪比<1的信号中提取规律，极易导致模型学习发散。

本文采用L=1监督学习：仅以单一时间步的传感器读数作为输入，使任务从"时序预测"退化为"状态映射"——给定当前时刻的传感器状态，预测当前时刻的电压。这一范式与大多数PEMFC退化预测文献保持一致，且避免了滑动窗口内信号被噪声稀释的问题。

然而，L=1舍弃了所有时序上下文，模型无法感知退化历史。为在保留L=1范式的同时引入时序信息，本文提出多步滞后增强策略：对于原始时间点t，不仅构造样本(t→t)，还构造(t-1→t)、(t-2→t)、(t-4→t)，其中箭头左侧为输入传感器读数的时间点，右侧为预测目标的时间点。每条样本附加一个lag标记列(lag/10，取值0.1, 0.2, 0.4)，使模型能识别输入来自多远的过去。

<mark>滞后步长的选择（lag=1,2,4）基于以下考量：lag=1（1小时前）提供最近的退化历史——在FC1准静态条件下，1小时内的电压变化已被噪声淹没，但仍能为LSTM的隐状态更新提供时序连续性；lag=2（2小时前）在数据扩展和信息冗余之间取得平衡——若仅使用lag=1，模型将从两个高度相似的样本（t和t-1）中学习，信息增益有限；lag=4（4小时前）引入足够长的时间距离，使传感器读数具有统计上可区分的差异——以FC2为例，4小时内纹波电流经历了8-16个完整周期，lag=4的样本在负载相位上与当前时刻统计独立，提供了真正多样化的训练视角。更远的滞后步长（如lag=8以上）存在递减收益——时间距离过大时，退化趋势本身的变化开始主导传感器差异，模型需要学习的"传感器→电压"映射因退化偏移而产生系统性偏差。lag=1,2,4的组合在"时间距离的多样性"和"退化趋势的稳定性"之间取得折中。</mark>

滞后增强带来三重收益：(1)数据量×3——从1151样本扩充至3453样本（FC1），有效缓解了单电堆数据量不足的问题；(2)多时间视角——同一目标电压对应三个不同滞后步长的输入，模型学会从不同时间距离推断电压，增强了对退化动态的理解；(3)兼容L=1回归范式——不需要改变模型输入维度，所有现有回归模型均可直接适配。

### 3.2.5 时序划分与归一化

本文采用50/10/40的时序划分策略：前50%作为训练集，中间10%作为验证集（用于早停和超参选择），最后40%作为测试集。划分在时序维度上进行——训练集包含退化早期数据，测试集包含退化中后期数据——这模拟了实际部署中"基于历史数据训练，预测未来退化"的应用场景。

<AI>需要说明的是</AI>，滞后增强后的三个副本各自独立进行时序划分，然后分别合并到训练/验证/测试集中。这保证了同一原始时间点的三个lag副本不会被分散到不同集合中，避免了数据泄漏。

最后，采用MinMaxScaler将X和y分别归一化到[0,1]区间。选择MinMax归一化而非Z-score标准化的原因是：24个传感器的量纲和取值范围差异极大（电压~3V，温度~50°C，流量~20 l/mn），Z-score归一化会导致大数值传感器主导梯度。MinMax将所有特征统一到相同区间，使Variable Selection的初始权重处于公平竞争状态。

## 3.3 失效阈值定义

依据相关文献[Jouin et al., IEEE TTE, 2016]，本文定义失效阈值为训练集初始电压的96%：
$$V_{failure} = 0.96 \times P_{95}(V_{train})$$
其中$P_{95}(V_{train})$为训练集电压的第95百分位数。FC1的失效阈值约为3.216V（初始电压3.350V），FC2约为3.161V（初始电压3.293V）。当预测电压低于该阈值时，判定电堆失效，其对应的时刻即为剩余使用寿命(RUL)的终点。

## 3.4 预处理对模型输入的影响总结

经过以上五步预处理，输入模型的最终数据规格为：(N, 1, 25)，其中N为增强后的总样本数(FC1: 3453, FC2: 3051)，1为时间步数(L=1)，25为特征维度(24传感器+1 lag标记)。训练/验证/测试比例为50/10/40，所有特征和标签均归一化至[0,1]区间。训练时不设置shuffle，保留样本的时序排列以维持LSTM的隐状态连贯性和物理约束的batch内时序差分。
