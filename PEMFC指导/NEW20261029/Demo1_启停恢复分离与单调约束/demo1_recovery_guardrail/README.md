# Demo 1｜把启停“回血”与长期衰减分开，再施加单调护栏

这个压缩包提供可以直接运行的 Python 示例、固定随机种子的模拟数据和已经跑出的结果。所有数据都是 **SYNTHETIC（模拟）**；没有使用真实 FC1 数据，也不声称 FC1 在 809 h 发生了这里的事件。`FC1_like_synthetic` 只是教学情景名，5 片电池也是可修改的模拟设定。

## 1. 一分钟运行

建议 Python 3.10–3.12。解压后进入本文件所在目录；正常运行不需要网络、GPU 或额外数据下载。

```bash
python -m venv .venv
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
# macOS / Linux:
# source .venv/bin/activate
python -m pip install -r requirements.txt
python run_demo.py
```

依赖安装只需首次进行。若已经有 NumPy、Pandas、SciPy、Matplotlib，可以直接运行最后一行。附带的 `requirements-tested.txt` 记录本次实际运行版本；常规使用采用 `requirements.txt` 的兼容范围。

默认读取已附的 `data/observations.csv`，不重新抽样、不覆盖模拟数据。结果输出到 `results/`。指定新的输出目录可以保留原结果：

```bash
python run_demo.py --output-dir rerun_results
python self_check.py
```

只有显式要求才重新生成数据；默认种子固定，生成结果可复现：

```bash
python run_demo.py --regenerate-data --output-dir regenerated_results
```

没有真值文件也能推断。以下命令完全不读取 truth：

```bash
python run_demo.py --no-evaluate --output-dir observation_only_results
```

外部观测不会自动配上随包模拟 truth；如未显式指定 `--truth`，默认只做推断。只有外部数据确有匹配的真值时才传入它：

```bash
python run_demo.py --observations your_observations.csv --output-dir real_run
python run_demo.py --observations your_observations.csv --truth your_matched_truth.csv --output-dir evaluated_run
```

第 3 张事件图优先显示已观测的 809 h 事件；若没有则显示最后一次已观测重启，若没有校准后重启则明确显示无可分析事件。文件名保留 `03_restart_at_809h.png` 以兼容默认示例，实际事件时刻以图内标题为准。

## 2. 它具体解决什么

观测到的电压回升可能来自可逆损失减少。把这种回升直接当作长期健康状态改善，会使未来衰减率和阈值交点产生偏差。本例采用同一平滑参数和同一 240 h 外推窗口，对比：

1. **原始电压直接外推**：简单且透明的基线，忽略可逆损失。
2. **恢复分离**：估计尚未恢复的损失，再重构长期状态。
3. **恢复分离＋单调护栏**：只约束长期状态估计的每一步不能增加。

这些都是可解释的小模型，**不是已训练的神经网络**。它们用来验证数据处理、因果顺序和物理假设，便于之后替换成自己的状态空间模型或神经网络。

## 3. 正确的恢复代数

先把电堆总电压除以串联片数，统一到单电池电压。设：

```text
V_op(t) = V_lt(t) + δ_op(t) − q_rev(t) + ε(t)
q_rev(t) ≥ 0
```

其中 `V_lt` 是在约定参考工况和恢复基准下定义的长期电压状态；`δ_op` 是工况偏移；`q_rev` 是相对该基准仍未恢复的电压损失。本例工况固定，`δ_op=0`，专门隔离恢复这一问题。

重启前后若长期状态和工况几乎不变，则：

```text
ΔV_rec ≈ q_before − q_after
V_lt ≈ V_op − δ_op + q_rev
```

**不能直接把恢复增量再从恢复后的电压里减一次。** 恢复增量和“当前仍剩多少可逆损失”是两个量。例如长期电压 0.670 V、工况偏移 +0.010 V、剩余可逆损失 0.003 V 时，观测为 0.677 V；正确恢复是 `0.677−0.010+0.003=0.670 V`。

## 4. 模型与严格的时间顺序

### 4.1 模拟机制

长期电压线性缓慢下降。自最近一次重启以来经过 `a` 小时，可逆损失为：

```text
q_rev(a) = A [1 − exp(−a/τ)]
```

模拟在 240、510、809 h 发生完整恢复式重启，`a` 重置为 0；记录开始时也假设处于所选恢复基准，即 `q_rev(0)=0`。真实数据若从未完成恢复的中途开始，需要另估初始可逆状态。真实电池不保证每次重启都恢复、也不保证完整恢复；完整恢复是本例的明确假设。启停也可能造成不可逆损伤，本代码没有把重启当作延寿建议。

### 4.2 初始校准，仅使用 0–360 h

`fit_recovery_model()` 对预设 `τ∈{40,41,...,150} h` 网格分别做有界最小二乘，拟合：

```text
V = a0 − βt − A[1−exp(−a/τ)]
β ≥ 0, A ≥ 0
```

网格由 `config.json` 提前声明，选择依据只有校准期残差。校准期必须至少包含一次重启，否则长期衰减与可逆损失可能难以分辨。没有使用留出集来选择 `τ`，也没有读取生成器的真实 `A、τ、β`。

### 4.3 从 360 h 开始，参数冻结、逐点在线处理

先算 `z_t = V_op−δ_op+q_hat`，再作 EWMA 平滑。校准期结束以前不输出“在线状态”，避免把回看拟合伪装成因果估计。

```text
无护栏： s_t = (1−α)s_(t−1) + αz_t
有护栏： c_t = (1−α)g_(t−1) + αz_t
         g_t = min(g_(t−1), c_t)
```

这里的 `Π_Co` 是对约束集合 `g_t≤g_(t−1)` 的**逐步欧氏投影**。它不等同于使用全寿命数据做离线单调回归，也不修改原始电压。护栏可能引入偏差或滞后，因此必须同时看预测误差；单调性本身不证明预测正确。

### 4.4 在 850 h 固定预测起点

所有方法使用各自状态序列的最后 240 h 拟合直线斜率，并从当前状态外推。三种方法的窗口和 EWMA 系数相同。恢复分离方法预测的是长期状态，因此**不需要知道未来重启时刻**。已附 851–2200 h 的观测和所有未来事件在推断前即被截断；这些数据不会回流到参数拟合。

有护栏方法的外推斜率限制为非正；若其他方法给出非负斜率，代码报告“该线性外推下没有有限阈值交点”，绝不解释为电池永远不坏。

## 5. 阈值必须说清楚

本例使用教学阈值：

```text
V_threshold = 0.96 × V0 = 0.96 × 0.720 = 0.6912 V
```

它表示**参考电压损失 4%**，不是“电压只剩 4%”，也不是所有燃料电池通用的报废标准。809 h 前后原始运行电压可能跨越这条线，但长期状态还没有到达同一阈值。`RUL` 用长期状态与同基准阈值定义；设备的实际运行保护阈值是另一个问题，通常还需预测工况和可逆状态。

本例所有电压均为单电池值，阈值与状态处于同一尺度。预测从 850 h 开始，RUL 是相对于该时刻的剩余时间。

## 7. 运行结果应该怎样读

先看 `results/03_restart_at_809h.png`，确认原始电压发生回升；再看 `01_recovery_decomposition.png`，检查估计的可逆损失是否在重启时减少、潜态是否保持合理趋势。最后看 `02_fixed_origin_forecast.png` 和 `metrics.json`，比较固定起点之后的预测与 RUL。

报告会同时保留历史 RMSE、未来 RMSE、RUL 绝对误差和向上步数。在本次固定种子的例子中，恢复分离显著缓解原始电压外推的偏差；护栏消除了向上步数，但它的 RUL 误差可能大于未加护栏模型。这个差异必须保留，不能为了“效果更漂亮”删掉。

## 8. 换成真实数据时改哪里

用自己的 CSV 替换 `data/observations.csv`，字段遵循数据字典。时间必须唯一、单调且等间隔；本例 EWMA 按采样步更新，不支持直接混入不规则间隔。先核实串联片数、时间单位和重启标志；如果工况变化大，应先用独立建立的工况校正方法生成 `condition_offset_v`。本例没有解决工况模型这一部分。

先设置初始校准期和最终预测起点，再训练。不能用未来全寿命数据确定均值、缩放系数、恢复幅度或阈值后又宣称在线预测。真实数据若没有长期状态真值，请用 `--no-evaluate`；不能拿模拟 truth 的指标冒充真实数据准确率。

如果只有部分恢复、多个恢复机制、诊断程序改变、潜态明显非线性或状态定义不满足单调假设，需替换恢复模型和状态更新，不应直接照搬本例的数值参数。

## 9. 可复现性和能力边界

固定随机种子为 `240809`，不需要联网。`results/runtime.json` 记录实际运行版本。数值文件使用高精度小数保存，重新运行可能因不同 BLAS/库版本出现极小浮点差异。

附带检查覆盖未来观测和未来重启标志的污染、不同预测起点的历史前缀一致性、truth 改动不会影响推断、RUL 边界情况以及恢复代数。它们验证实现的关键约束，不等同于真实工况外推有效性证明。

本例用于讲课、算法原型和可复现的处理流程；投稿还需要真实数据、独立留出评估、强基线、参数敏感性和不确定性报告。
