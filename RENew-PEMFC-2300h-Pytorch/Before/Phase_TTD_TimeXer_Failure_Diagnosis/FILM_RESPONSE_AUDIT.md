# FiLM response audit

`C_delta_mV = C_P2 - C_P1` is analyzed without changing the checkpoint. In state-correct, low-amplitude-error points, Fold 1 has mean C delta +0.407 mV and P95 absolute delta 22.649 mV; Fold 3 has +3.059 mV and 7.872 mV. Those state-correct groups are net favorable to P2.

The harmful S1 groups have large correction changes: Fold 1 P95 absolute C delta 343.455 mV and Fold 3 215.328 mV. However those points also have state and current errors, so the data do not identify excessive FiLM response *despite accurate conditions*. The optional FiLM sensitivity run is explicitly NOT_RUN because no pre-registered, train-supported perturbation radius was available and no single mechanism satisfied the dominance rule.
