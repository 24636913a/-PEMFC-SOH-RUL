The cell EIS measurements are named as follows:
currentOfTheExternalLoad_loadOfTheAmplitude_loadOfTheTestbench
The average load of the external load together with the test bench load is the nominal load of the measurement. Load fractions below 1A are denoted by a dash in the file name to avoid violating common naming conventions.
i.e. 50A_25-2A_ampl_454A_tst --> 50 A external Load, 25.2 A amplitude + 454 A testbench load resulting in 504 A nominal load 


The spatially resolved EIS measurements are named as follows:
currentOfTheNominalLoad_loadOfTheAmplitude_loadOfTheTestbench
The average load of the external load together with the test bench load is the nominal load of the measurement. Load fractions below 1A are denoted by a dash in the file name to avoid violating common naming conventions.
i.e. 504A_35-2A_ampl_454A_tst --> 504 A nominal Load, 35.2 A amplitude, 454 A testbench load resulting in 50 A external load 

In the spatially resolved EIS measurements, the file "..00" contains the data of the reference cell.


The EIS and spatiallyResolvedEIS data are provided as .zip-files for reasons of number of files and filesize. After unpacking, the files are available as raw .txt-files (ASCII).
