# RealHyFC启停恢复分离与分段单调约束

## 只运行一个文件

打开 `RealHyFC_启停恢复处理.py`，选择项目Python环境，点击 **Run All Cells**。也可在本目录终端运行：

```powershell
python -B .\RealHyFC_启停恢复处理.py
```

**每次都会重新识别候选事件、拟合历史区间参数、计算恢复候选分量、执行分段单调约束并生成全部图像。已取消“仅补图”入口，不读取旧处理结果回放。**

程序使用既有原始秒级只读缓存（不是旧模型预测缓存），不重新解析原始CSV，不训练神经网络。依赖见 `依赖.txt`。`SHOW_FIGURES = True` 表示在VS Code中显示图像，同时保存文件。

每次结果另存 `../输出结果/本次时间戳/`，不会改动旧结果。

## 输出与“分离成功”的区别

本程序针对Train冻结的约0.558 A/cm²固定负载平台，不直接把任意动态工况电压拆成健康状态。

候选模型是：

`V_observed = a - beta*(OpHrs2-t0) - A*(1-exp(-age_wall/tau)) + residual`

- `q_reversible_candidate_V`：指数形状的候选可逆损失。
- `recovery_corrected_V = voltage_V + q_reversible_candidate_V`：候选恢复校正电压。
- `slow_model_candidate_V`：模型假设的慢变基线，不是真实不可逆健康标签。
- `model_residual_V`：仍未解释的电压变化，完整保留。
- `reconstructed_voltage_V`：三个分量代数重构的电压。重构一致只是计算正确，不证明物理分离正确。

有可计算拟合时，**即使可靠性判定为BLOCKED，也保存候选分量和曲线**，并明确标为未验证。样本不足、缓存身份错误或数值拟合失败时保留原因，不伪造分量。不会放宽原5%拟合改善、参数边界及稳定性判据来制造通过结果。

## 全时域离线图与标定后状态

- 图中默认显示 `offline_*` 全时域离线候选曲线；Train内使用事后标定参数，不能当作当时在线可得的健康输入。
- 不带 `offline` 的滤波状态从Train标定截止后才开始，使用已固定参数。
- 单调约束只在各连续滤波段内生效；跨segment、长缺口或未知恢复年龄会重置，不能宣称全寿命严格单调。
- CSV新增 `filter_block_id`、`filter_reset_reason` 及对应 `offline_*` 字段，记录哪里重置、为什么重置。

## 本轮核查修复

原识别器会跨过后续零电流段，把同一次重新加载重复认领。旧结果830条可用候选中存在24条重复。本版遇到重新归零立即结束原事件的搜索，保留拒绝记录，不静默去重。旧结果不改写。

旧代码默认为仅补图且资格失败就不输出候选分量，偏离了“每次实际分离”的使用目标；现已取消该默认和补图入口。对未知恢复年龄仍不填值，不把例行零电流循环等同于已确认Air-Air恢复。

初次运行的BLOCKED结论保留：恢复年龄主要约0.31–3.41h，候选时间常数达到96h且拟合改善很小。因此本次修复不等于已经证明真实恢复分离成功。

本轮仅运行小型合成数组检查与已有CSV的只读核验，没有重跑全量缓存处理或真实数据拟合。详细检查证据见 `代码检查说明.md`。历史代码保留在 `历史副本`，现有原始数据和旧输出不变。
