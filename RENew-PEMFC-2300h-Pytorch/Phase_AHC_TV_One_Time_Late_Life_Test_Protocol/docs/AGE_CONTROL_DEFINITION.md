# Nominal-age control definition

The sole age control is `Y = alpha + beta A_nominal_h`, with beta constrained to be nonpositive. It was fitted once by constrained least squares to the six Development nominal labels and frozen targets, producing alpha 0.9853267436259231 and beta -0.0000083952663925. It is not an exact-age physical degradation model and will never be refitted with Test information.
