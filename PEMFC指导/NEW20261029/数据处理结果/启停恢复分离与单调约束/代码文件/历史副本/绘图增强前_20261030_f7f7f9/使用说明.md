# RealHyFC启停恢复分离与单调约束

## 运行

在VS Code中选择原项目Python环境，打开 `RealHyFC_启停恢复处理.py`，点击 **Run All Cells**（文件使用 `# %%` 单元），也可直接运行整个文件。只运行前面的定义单元不会处理数据，最后一个单元调用 `run()` 才开始。

也可在本文件夹的终端执行：

```powershell
python -B .\RealHyFC_启停恢复处理.py
```

依赖为NumPy、pandas、SciPy、Matplotlib，见 `依赖.txt`。本次只编写文件，没有安装软件，没有执行程序、拟合、绘图或单元测试；需要用户自行实际运行验收。

输出写入同级 `../输出结果/年月日_时分秒_微秒_随机后缀/`。每次建立独立目录，绝不覆盖旧结果。PNG以300dpi保存，同时输出PDF、逐平台CSV、绘图CSV、参数与身份记录。图像在VS Code交互窗口显示；普通终端的 `plt.show()` 可能需要关闭图窗后继续。如只想保存，将配置 `show_figures` 改为false。

## 与Demo1相比做了哪些适配

1. **真实来源**：复用20261022原始审计的只读秒级缓存以及阶段2A平台表，不读取Demo模拟数据，不重新解析原始CSV。依赖目录必须保留。程序先校验清单、平台表、冻结负载选择的SHA，以及五个二进制缓存的大小和SHA。输入改变时停止，不自动接受新版本。
2. **电压单位**：缓存 `mean_voltage_V` 已经是历史协议定义的单体均值，不再除以10，也不将U6当作正常电池加入均值。
3. **固定负载**：复用Train确定的 `156||156.800`、DOWN进入方向，实际j约0.558 A/cm²。复用原B60平台稳定性与压力条件，只去掉拒绝项 `OTHER_ENTRY_RECOVERY_GROUP`，以便观察不同恢复年龄。其他拒绝项保留，A60/B60历史结果不变。这是新的探索性样本集合，不等于原正式B60循环观测。
4. **不伪造工况修正**：没有可靠温压校准系数，因此不将其设成0假装已修正；只输出实际温压对照。B60温度可比性限制仍在，固定负载不代表全工况等价。
5. **候选启停**：实际电流绝对值≤0.1A持续观测至少60s，之后120s内观测到≥1A，且不跨segment/采样间断。事件时间是重新加载实际被观测到的时刻。它不是已经证实的停机、Air-Air操作或“完全恢复”。文件开始、缺失时段和低电压均不自动认定为启停。60s、120s等是本程序预先写定的操作性规则，不是从本次结果反推的物理阈值。
6. **两种时钟**：恢复年龄按实际日历时间；慢变趋势和滤波按实际OpHrs2。平台均值的恢复基函数在原始平台采样时刻求均值，不拿名义周期代替实际时间。事件必须早于平台首条采样才可使用。每个CSV保留原始行、文件ID及测量可用时间。
7. **参数拟合**：只用原冻结选择中的Train边界（1383.195476h）前、恢复年龄已知的平台。最少40个平台、3次候选启停且每次至少5个平台；每次启停总拟合权重相同。固定时间常数网格与参数界限见配置。时间常数范围0.25–96日历h只是本探索性模型范围，不能据此解释更快的瞬态恢复。
8. **拒绝机制**：趋势/恢复高度混淆、时间常数落在搜索边缘、拟合改善不足、参数触界或敏感性过大时，分离状态为BLOCKED。仍保存真实观测、候选事件、温压图和拟合诊断；恢复项和分离后单调状态保留NA，不补0、不假装成功。首次运行可能出现BLOCKED，这是有效输出。
9. **时间因果**：Train内修正仅作离线标定诊断；滤波状态只从标定截止后开始。后期观测不重新选择参数。事件识别虽扫描全文件，但每个平台只使用其开始前已经观测的重新加载。未知恢复年龄不外推填补。
10. **单调约束**：仅对恢复校正后的估计状态投影，不改原始电压；非等间隔因果EWMA使用6运行小时半衰期。segment改变、有效观测间隔超过24运行小时或恢复年龄未知时重置。它不是全寿命不可逆损伤的证明，也可能产生向下累积偏差。

## 输出

- `01_固定负载电压与候选启停.png`：原始固定负载观测、候选启停位置与恢复年龄。
- `02_恢复分离与单调约束对照.png`：原始EWMA、分离后EWMA、单调保护与保护偏移；无资格时明确保留NA。
- `03_平台温压与负载条件.png`：真实温度、压力、电流密度。
- `04_Train恢复时间常数敏感性.png`：有足够拟合数据时生成，仅显示Train观测拟合残差，不是健康真值误差。
- `05_候选启停后的平台响应.png`：存在已知事件年龄时生成，固定按时间顺序展示最早四次，不挑有利案例。
- `表格/恢复分离与单调约束逐平台结果.csv`：全部接受平台的实测值、候选恢复项、校正值、未约束/单调状态、时间和来源。
- `表格/平台排除记录.csv`、`候选启停事件.csv`：保留拒绝原因及未确认事件。
- `运行记录/恢复模型参数与资格.json`：拟合规则、Train数据量、参数与拒绝原因。
- `运行记录/输出SHA256.csv`：输出文件追溯；失败时有 `失败记录.txt`。

## 科学边界

本程序没有不可逆健康真值，不输出“分离健康RMSE”、SOH、RUL或恢复成功率。它检验的是Demo1形状假设能否在真实固定负载数据上得到有限支持。即使数值筛查通过，也只是 `EXPLORATORY_DECOMPOSITION_ONLY`：温压、扫描/运行状态及普通波动仍可能混入候选恢复项。

全寿命图属于探索性离线分析。后期数据已经被研究使用，不能将本图称为新的独立Test。本程序不修改阶段0至2D、F2、Demo1、原始审计缓存或历史结果，也不执行Git操作。
