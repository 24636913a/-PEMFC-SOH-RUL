# Cycle-definition contract

No segmentwise verified protocol schedule is available in the authorized sources, so the primary route is `OPERATION_POINT_SEQUENCE`, not a protocol-defined or fixed-19-bin cycle.

Only the earliest EARLY Development pure-bin sequence supplies the frozen template. Tokens combine `operation_point_mode` and `set_current_A_mean` rounded to three decimals. The period is selected from the pre-registered 12–30-bin candidates using exact lag-token agreement in eligible EARLY sequences; ties use the shorter period. The earliest eligible sequence of that period is the sole template. The template is then scanned forward unchanged.

An accepted cycle is a complete, exact template match wholly within one temporal segment, split and age stratum; every constituent bin is valid, pure, coverage-qualified and free of startup/shutdown/gap flags. Its summary is available only at the cycle end. A 19-bin construction is recorded only as a sensitivity and can never replace the primary route or rescue a failed gate.
