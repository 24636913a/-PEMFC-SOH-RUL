# Demo 2｜动态工况下的 SOH 连续估计与 8 次诊断锚点校准

这是一个可以直接运行的教学实验：日常电压随负载波动，完整寿命只有 8 次极化诊断；先把日常电压放到一致的参考工况，再在诊断到达时校准健康状态。代码、模拟 CSV、已运行结果和自动检查均已附带。

**所有数据均为模拟，未使用 FC1 或 RealHyFC 实测数据。** “动态工况”借鉴真实应用中的问题类型，时间、噪声、退化率及诊断次数均为可修改的示例设定，不能据此声称真实数据集达到相同精度。

## 1. 一分钟运行

需要 Python 3.10 或以上。建议先建立独立虚拟环境，在本目录执行：

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python run_demo.py
```

默认读取包内 `data/`，不重新生成数据、不访问网络、不训练大型网络。安装依赖本身需要可用的软件源。运行后覆盖本目录 `results/`；想保留原结果可执行：

```bash
python run_demo.py --output-dir my_results
python verify.py
```

修改 `config.json` 的模拟参数后，显式重新生成数据：

```bash
python run_demo.py --regenerate-data --output-dir regenerated_results
```

该参数会重写 `data/` 中的模拟 CSV，请先备份自行放入的真实数据。仅修改估计器参数而不重造数据时，直接运行普通命令即可。

已验证环境：Python 3.12，NumPy 2.3.5，pandas 2.2.3，Matplotlib 3.10.8。更精确的本次环境见 `results/environment.json`。

## 2. 这个 demo 解决什么

研究对象是相同参考电流密度 `j_ref = 0.8 A/cm²` 下的、统一温度条件和诊断协议下的单电池平均电压。健康度定义为：

```text
SOH(t) = [V0(j_ref) - d_c(t)] / V0(j_ref)
```

我们把图中“8 根诊断柱”解释为 **8 个不同时间的体检会话**。每次会话测 21 个电流密度点，构成一条极化曲线；它们不是一条曲线上仅有 8 个采样点。

模拟有 361 个日常观测点（0–1800 h、间隔 5 h），诊断在 0、260、520、780、1040、1300、1560、1800 h 到达。0 h 只建立初始基准；其余 7 次用于在线校准。1800 h 的诊断不能改善 1800 h 之前已输出的结果。

## 3. 电压模型：为什么需要校准

模拟观测方程为：

```text
Vop(t,j) = V0(j) - d_c(t) - d_r(t)*(j-j_ref)
           + alpha_T*(T-T_ref) + b(t) + measurement_noise
```

- `d_c`：参考电流密度处的长期电压损失，V。
- `d_r`：极化曲线斜率的增加量，Ω·cm²。
- `alpha_T*(T-T_ref)`：通过独立工况标定得到的温度修正；本例可直接测温。
- `b(t)`：仍未被工况模型解释的慢变偏差，V；不提供给估计器。

直接计算 `Vop(t,j) / V0(j_ref)` 会混入不同电流和温度的影响。用初始曲线作标准化时：

```text
V_standardized = Vop - alpha_T*(T-T_ref) + V0(j_ref) - V0(j)
```

它仍包含 `-d_r*(j-j_ref) + b(t)`，因此不会自动等于真正的长期参考电压。后续极化诊断就是用来补充这些缺失信息的。

**可辨识性是本例的关键限制。** 单个日常电压只能给出 `d_c + d_r*(j-j_ref) - b`，不能凭空同时辨认长期衰老与未知工况偏差。完整极化扫描在统一条件下提供 `d_c` 与 `d_r` 的额外约束；两个诊断之间仍需依赖状态演化、偏差缓变等假设。

## 4. 算法实现

### 第一步：只用初始诊断拟合 V0(j)

`estimator.py::fit_initial_reference()` 使用 0 h 诊断拟合当前电流范围内的二次曲线。它没有读取任何后续诊断或全寿命统计量。这里的二次曲线只是有限工作区间的近似，不代表完整极化机理；实际数据可换成合适的单调样条或物理极化模型。

### 第二步：日常观测更新四维状态

```text
x = [d_c, d_c 的变化率, d_r, b]
d_c(t+dt) ≈ d_c(t) + rate(t)*dt
```

其余状态采用带过程噪声的缓变模型。条件修正后的日常观测满足：

```text
y = V0(j) - [Vop - alpha_T*(T-T_ref)]
H = [1, 0, j-j_ref, -1]
y = H*x + noise
```

采用普通线性 Kalman 滤波；数值实现使用 Joseph 形式更新协方差。`config.json` 中 `estimator` 与 `generator` 完全分离，估计模块只接收前者。初始退化率设定是有较宽方差的先验，不是从真实潜态读取的答案。

### 第三步：诊断到达时更新

将新的受控极化扫描与初始曲线作差，通过最小二乘得到：

```text
V0(j) - V_diagnostic(t,j) ≈ d_c + d_r*(j-j_ref)
```

再把 `[d_c, d_r]` 及其测量误差协方差作为两个额外观测送入滤波器。协方差加了噪声下限，近似包含初始基准扫描误差；这不是对所有实验条件成立的精确误差模型。

程序逐时处理，只有 `diagnostic_time <= current_time` 的扫描才会被使用。当前示例假设诊断采集完成时刻与结果可用时刻一致，且与日常样本对齐；若诊断有较长采集/处理延迟，应分别记录采集时刻和可用时刻，并加入延迟状态更新。既不能把未来结果假装提前知道，也不能简单把旧测量的时间戳改成到达时刻，假装它测的是到达时的当前状态。

## 5. 对照与结果

有四组输出：

| 方法 | 用初始诊断 | 修正已测温度/初始曲线 | 用后续诊断 |
|---|---|---|---|
| 原始 `Vop / V0(ref)` | 分母 | 否 | 否 |
| 初始曲线标准化 | 是 | 是 | 否 |
| 同型 Kalman、无后续锚点 | 是 | 是 | 否 |
| 因果稀疏锚点融合 | 是 | 是 | 仅到达之后 |

主要消融是后两组：代码与参数相同，只切换是否吸收后续诊断。前两组帮助展示为什么原始电压并不等于健康度。

固定数据本次结果（单位是 **SOH 百分点 pp**，不是相对百分比）：

| 方法 | 全部样本 RMSE | 排除诊断时刻后的 RMSE |
|---|---:|---:|
| 原始电压比值 | 5.9465 | 5.9045 |
| 初始曲线标准化 | 1.1491 | 1.1598 |
| 同型 Kalman、无后续锚点 | 0.8993 | 0.8994 |
| 因果稀疏锚点融合 | 0.2486 | 0.2509 |

这是本次模拟运行的结果。锚点融合没有完全消除偏差，两个锚点之间仍可能漂移。初始 0–260 h 区间没有后续诊断可用，因此两个滤波器在此区间应完全相同。

`interval_metrics.csv` 进一步逐段报告诊断之间的误差，排除两个诊断端点；`anchor_updates.csv` 报告每次诊断前后的即时变化。不要只拿诊断发生时的误差代表整段在线精度。

结果可直接查看：

- `results/01_dynamic_load_and_health.png`：负载、实际电压、原始比值、校准后的 SOH。
- `results/02_diagnostic_scans_and_loss.png`：8 条诊断扫描与长期损失估计。
- `results/03_anchor_updates_and_interval_error.png`：校准瞬间和两次校准之间的误差。
- 同名 `.svg` 可在矢量软件中编辑；数据由 CSV 保留。
- `results/RESULTS.md`：本次运行的中文说明。

## 6. 防止“偷看答案”的检查

`verify.py` 包含 9 项有意义的自动检查：

1. 截断未来日常观测和诊断，较早时刻的估计不变。
2. 修改未来电压和未来诊断，较早估计不变。
3. 真实推断入口在缺失 truth 和放入不可解析 truth 两种情况下结果完全相同。
4. 无锚点对照确实不吸收后续诊断，且使用同一估计器。
5. 默认模拟数据核对元数据中的 8 个诊断会话、每次 21 点；修改配置并重新生成后，核对新的模拟元数据。
6. 0 h 只初始化，后续更新次数等于实际已到达的诊断会话数（默认 7 次）。
7. 校准严格发生在该扫描的可用时间。
8. 已知损失和斜率的理想扫描可恢复正确参数及单位。
9. Joseph 更新后的协方差保持半正定。

`truth_for_evaluation_only.csv` 只在估计及预测 CSV 已保存之后被读取，用于误差计算和绘图。删除 truth 后仍可完成估计；无法计算的准确率指标会被明确跳过。

本例不是训练/测试划分后的离线泛化测试。它检验的是 **固定参数在线估计流程的因果性**，在同一模拟机制上演示工作原理。参数选择、真实数据泛化和置信区间覆盖率仍需另行研究。

## 7. 换成真实数据

保留字段名并替换 `operation.csv` 与 `diagnostics.csv`，建议放在独立 `my_data/` 目录，避免覆盖演示数据。真值文件是可选的。运行示例：

```bash
python run_demo.py --input-dir my_data --output-dir my_real_results --skip-demo-fixture-check
```

注意：替换数据后，结果是否准确仍取决于正确的工况标定和估计参数；不要把本模拟场景的生成参数当成真实电堆先验。

| 文件 | 字段 | 含义 |
|---|---|---|
| operation.csv | time_h | 严格递增的运行/结果可用时间，h |
| operation.csv | current_density_a_cm2 | 电流密度 A/cm²，不是电流 A；换算需有有效面积 |
| operation.csv | temperature_c | 温度，℃ |
| operation.csv | voltage_cell_v | 单电池平均电压；电堆电压需除以明确的串联电池数 |
| diagnostics.csv | session_id | 诊断会话编号，同会话多行 |
| diagnostics.csv | time_h | 该扫描采集完成且结果可用的共同时间，与日常样本对齐；本例假设处理延迟可忽略 |
| diagnostics.csv | current_density_a_cm2 | 扫描中的电流密度 |
| diagnostics.csv | temperature_c | 诊断温度 |
| diagnostics.csv | voltage_cell_v | 统一诊断条件下的平均单电池电压 |

真实数据适配时至少要完成：统一电压口径；清理无效/停机样本；显式对齐诊断可用时间；独立标定温度、压力、湿度等工况影响；保证正常运行电流处于基准扫描支持范围；用训练段选择滤波参数；按时间或整电堆留出独立验证。

诊断次数不是算法写死的参数。修改 `generator.diagnostic_times_h` 并重新生成数据，可以直接运行 7 次或其他数量的诊断。真实输入没有 `metadata.json` 时采用通用形状检查；若沿用了旧的模拟元数据，可删除它，或加 `--skip-demo-fixture-check` 跳过模拟会话/点数断言，仍保留因果性、truth 独立性等检查。

**不能得出的结论：** 八次体检一定足够；二维神经网络必然不能训练；所有残余偏差都能被这四个状态识别；本次模拟 RMSE 等于真实电堆精度。复杂模型是否合适，要结合样本独立性、先验信息、参数数量和外部验证判断。
