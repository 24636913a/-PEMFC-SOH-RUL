# PEMFC 健康状态与寿命预测研究

> **给实验指导老师和项目合作者的阅读入口**  
> 本仓库记录质子交换膜燃料电池（PEMFC）的电压预测、运行状态分析，以及向健康状态（SOH）估计和剩余使用寿命（RUL）预测拓展的研究过程。它是持续更新的研究仓库，**不是所有目录都代表当前可运行的正式模型或已经验证的论文结果**。

## 一、研究在做什么

研究的长期目标是利用燃料电池长期运行数据，识别性能退化并估计 SOH / RUL。当前阶段的重点更具体：**利用RealHyFC真实运行数据中的历史观测，预测未来一段时间的平均单体电压。当前已保存的Top10预测输入主要涉及电压、电流和温度相关特征，尚未选入压力特征；入口压力等变量目前主要用于独立的电压突变及启停关联审计，后续是否加入预测模型仍需实验验证。** 重点分析动态工况以及启停/恢复运行引起的突变。

仓库包含两类不同阶段的实验，阅读时请勿混淆：

| 研究阶段 | 数据时间尺度与任务 | 状态 |
| --- | --- | --- |
| 早期 RealHyFC 研究 | 约 0.5 h 分辨率；曾开展多步电压变化量预测、模型筛选、物理与健康表征研究 | 历史阶段，具体结论见各阶段报告 |
| **当前关注的 RealHyFC 秒级研究** | 原始约 1 s 数据；**过去 300 秒 → 未来 120 秒**，直接预测平均单体电压（V） | 已完成数据与突变事件审计；完整模型训练尚未完成 |

目前**不能把短期电压预测结果直接等同于已经实现 SOH 或 RUL 预测**。

## 二、当前秒级实验：一分钟看懂

- **数据**：RealHyFC 耐久性测试的 17 份 `Loadcycle` 原始 CSV，已审计总计 **8,604,654 条**记录；不先聚合为半小时数据。
- **预测对象**：U1–U5、U7–U11 共 10 个有效单体电压的平均值；U6 保留独立诊断，不参与这一平均值。
- **输入 / 输出**：每个预测起点使用此前 300 个连续秒级观测，预测其后 120 个秒级平均电压值。
- **候选模型**：普通 LSTM 与改进的 F2（基于 TFT，含历史因果卷积分支和运行状态融合门控）。两者应按同一数据协议公平比较。
- **当前划分**：按原始时间顺序约 70% Train、10% Validation、20% 后段数据；历史研究已接触过后 20%，**不应将其声称为完全未使用的独立盲测集**。
- **信息约束**：特征筛选和标准化只使用 Train；预测时不读取未来真实电流、未来电压或事后才知道的启停时间；最终验证覆盖全部合法逐秒起点。
- **评价指标**：RMSE（mV）、MAE（mV）、R²，以及 1–120 秒各步长的误差。

详细技术协议：[秒级 300→120 研究说明](RENew-PEMFC-2300h-Pytorch/RealHyFC_Raw1s_Rolling_300to120/README.md)。

## 四、目前已经发现什么

### 1. 电压突变与启停运行状态密切相关

在全量秒级审计中，使用固定规则识别到 **15,578 个操作性电压事件段**，其中有 **808 个低/零电流阶段的正向电压恢复代理事件**。这些是按算法定义的事件段，**不能直接视为 15,578 次真实设备故障或 808 次已核实的物理启动**。

在具有明确起止记录的可比较零电流停留段中：

- 较长停留段：**电压恢复之后约 65 秒**重新给出正电流指令；
- 较短停留段：对应间隔通常**约 7 秒**。

这是对实验装置恢复流程的事后观察，不意味着模型能在电压跃升之前就知道它会在哪一秒发生。

### 2. 温度、压力可能提供运行前兆，但效果有限

新的突变关联审计分别比较事件前、事件瞬间与事件后的变量变化，并加入普通运行时刻的对照。Validation 中，入口压力在事件前 120 秒内发生显著变化的比例高于普通对照；而冷却液温度的区别较弱。此前的简单固定规则也只对部分恢复事件提供了约 30–60 秒的预警，**不能声称所有突变已经可被准确提前预测**。

- [全量启停与前兆审计报告](RENew-PEMFC-2300h-Pytorch/RealHyFC_Raw1s_Rolling_300to120/audits/Startup_Precursor_Audit/runs/20261022T071957_960946Z_b1590612/AUDIT_REPORT.md)
- [电压事件关联分类修订报告](RENew-PEMFC-2300h-Pytorch/RealHyFC_Raw1s_Rolling_300to120/audits/Voltage_Event_Classification_Refinement/runs/20261022T173225_569409Z_da51bc52/REPORT.md)

上述分析表明多种传感器信号与电压变化**有关联**，但尚未凭此确定每次跳变的唯一物理原因。

## 五、当前主要困难：训练时间过长

最近一次秒级 F2、Seed 202 训练采用全部合法训练起点、起点间隔 1 秒：**6,017,348 个训练窗口**；微批量 `batch_size=16`、梯度累计 2、最多 450 Epoch，并在每轮进行完整逐秒 Validation。

已保存的真实运行日志显示：

- **只完成 1 个 Epoch**，该轮记录的训练与验证总耗时约 **55,277 秒（15.35 小时）**；
- 随后用户手动中断，运行状态为 `FAILED_OR_INTERRUPTED`；
- 保留了该轮的日志和最佳权重快照，但**尚无完成全部训练后的正式性能结论**。

[中断运行记录及源码快照](RENew-PEMFC-2300h-Pytorch/RealHyFC_Raw1s_Rolling_300to120/runs/20261022T014716_543827Z_F2_seed202_70de07ea/)。该次仅一个 Epoch 的临时验证指标**不得作为最终模型成绩**。

现阶段尤其希望指导老师帮助审查：数据加载和反复生成窗口特征的开销、训练起点的高重叠问题、逐轮完整验证的时间成本，以及怎样在不泄漏未来信息、不改变原始秒级预测任务的前提下控制训练资源消耗。

## 六、准备研究但尚未正式验证的方向

- 从历史实际电流和设定电流构建更清晰的**启停状态特征**；
- 研究**状态持续时间**、压力和温度变化是否有助于提前识别电压恢复；
- 对比普通 F2 与加入运行状态信息的 F2，特别关注启停事件附近的预测误差；
- 之后再根据运行成本，决定是否实施独立的训练效率优化。

这些都是研究计划，**不是已经训练完成的改进模型**。在获得真实未来启停控制计划的发布时间证据之前，不把事后记录的未来指令当成预测时已知信息。

## 七、如何使用本仓库

建议首次阅读依次查看：**本README → 训练入口与 `raw1s/` → 中断训练记录 → 两份突变审计报告**。如果需要复现旧实验，再到 `Before/` 阅读对应阶段的冻结协议、版本信息和恢复说明。

本仓库保留研究过程中有效与无效的尝试。请以每次实验自身的 `run_manifest.json`、配置、原始结果和状态标记为准，不将历史局部最优结果、未完成运行或后验诊断当作最新正式结论。
