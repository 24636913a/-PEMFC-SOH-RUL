## 导师反馈（2026-07-25）

1. 论文写得很乱套，连改的冲动都没有
2. 要求学习别人文章的结构
3. 缺失内容：**意义**没有、**背景**没有、**国内外研究现状**没有、**结论不明显**
4. 标准结构参考：引言 → 方法 → 实验设置 → 结果与讨论 → 结论与展望
5. 形容好结构是"简约而不简单"

**How to apply:** 
- 每次修改论文前，先检查是否有独立的研究背景与意义节、国内外研究现状节
- 结构严格对照：Introduction → Methodology → Experimental Setup → Results and Discussion → Conclusion
- 结论 3 条核心即可，不要 7 条
- 大纲通过后再写正文，不要急
