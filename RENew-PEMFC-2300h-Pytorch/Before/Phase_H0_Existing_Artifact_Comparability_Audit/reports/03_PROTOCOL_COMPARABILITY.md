# Protocol comparability

Identical target keys do not remove training-protocol confounding. H0 variants are independently trained history-only/direct-output artifacts; SA artifacts use a joint base-plus-FiLM correction with nine causal future-condition inputs and a separate OOF/purge construction. H0-Life additionally changes the history representation. Therefore H0-vs-SA is descriptive reuse, not a formal future-condition-only ablation.
